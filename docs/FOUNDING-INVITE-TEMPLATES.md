## Follow-up cadence

- **Day 0:** send invite
- **Day 3:** if no reply — "Hi {First Name}, just bumping this — the founding
  owner slots are going fast. Want me to set you up today?"
- **Day 7:** if still no reply — one last nudge, then move on. 20% reply rate is
  normal for cold-ish outreach; the warm network should convert higher.
- Track replies in the support ticket system or a simple sheet: name, property
  count, invited date, status (sent/replied/onboarded/declined).

## Onboarding the yes

1. Send them `https://krtaker.com/register.html` (14-day trial path; we extend to
   12 months via the panel)
2. Tell them to pick the plan that fits — we adjust the period in the backend
3. Walk them through: add property → add tenant → generate first invoice
4. Note: **payments aren't live yet** (gateway KYC pending) — nothing to pay,
   which is exactly why the founding offer is free
